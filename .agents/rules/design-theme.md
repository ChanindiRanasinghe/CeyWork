# CEYWork Design & Color Theme System

All views, Livewire components, and UI pages built for CEYWork must strictly follow this visual design system and color palette:

## Core Color Palette
- **Teal Sidebar / Brand Canvas**: `#00b4a2` (Primary Brand Teal for main sidebar, hero headers, and primary brand panels)
- **Crimson Red Accent**: `#b91c1c` / `#cc0000` (Used for primary CTA buttons, active sidebar navigation pills, unread count badges, and logo badge background)
- **Warm Cream Page Canvas**: `#fdfbf4` / `#faf8f0` (Main content area background)
- **Container Cards**: `#fcfbf7` / `#ffffff` with `border border-slate-200/80` and `rounded-3xl` or `rounded-2xl`
- **Emerald Green**: `#059669` / `#047857` (Account activation button, active status badges, positive growth metrics)
- **Amber / Gold**: `#d97706` / `#b45309` (Warning banners, pending leave status, high priority alerts)

## Typography & Components
- Font: Modern Sans-Serif (Inter / Instrument Sans)
- Primary Buttons: `bg-[#b91c1c] hover:bg-[#a11818] text-white font-bold rounded-xl`
- Brand Logo: Official logo image at `public/images/logo.png`
